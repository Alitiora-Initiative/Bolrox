Features

Designed around evidence quality, not signal volume.

Multi-source prices

Yahoo Finance with Stooq fallback, SQLite caching, and interval-aware freshness windows. Prices are never invented.

Technical battery

EMA, ATR, RSI, MACD, ADX, Bollinger bands, and swing structure — computed in code on every run.

Macro context

Yields, VIX, and equity proxies from free sources. Optional FRED key for deeper macro series.

Positioning (COT)

CFTC Commitments of Traders via the public reporting endpoint for net non-commercial exposure.

Confluence scoring

Weighted blocks for HTF bias, location, momentum, macro, events, and sentiment → grade A / B / Watch / No-trade.

Trade construction

Hard 1.5 R:R floor, multi-target ladder, risk-based position size, and explicit invalidation text.

Report engine

Timestamped Markdown report (~1,000 words) plus structured signals.json under dated output folders.

Zero paid APIs

Core pipeline runs on free public data. No credit card required for baseline operation.
