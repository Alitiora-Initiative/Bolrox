Features

Everything designed around evidence, not excitement.

Multi-source price data

Yahoo Finance + Stooq fallback with SQLite caching and freshness windows. Never invents prices.

Technical battery

EMA, ATR, RSI, MACD, ADX, Bollinger, swing structure — all computed in code.

Macro & intermarket

Yields, VIX, equity proxies via free sources. Optional FRED key for richer macro.

Positioning (COT)

CFTC Commitments of Traders net non-commercial via public endpoint.

Confluence scoring

Weighted blocks (HTF bias, location, momentum, macro, events, sentiment) → grade A / B / WATCH / NO_TRADE.

Trade builder

Hard R:R floor of 1.5, position sizing from risk %, invalidation rules, multi-TP ladder.

Report engine

~1,000-word Markdown report + signals.json + optional charts.

Zero paid APIs

Runs with free data only. Optional free FRED key for extra macro depth.

Educational analysis only. Not financial advice.
