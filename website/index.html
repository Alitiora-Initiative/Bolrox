Outputs

What every run produces

Structured artifacts designed for review — not hype.

Analysis report

Approximately 1,000 words of Markdown covering regime, levels, confluence, and explicit invalidation conditions.

Trade signals

Entry, stop, multi-target ladder, risk-to-reward, suggested size, and probability — only when thresholds are met.

No-trade is valid

When confluence is weak, data is stale, or risk is asymmetric, the system stays flat. Silence is a feature.

Principles

Non-negotiable rules

Built for accuracy over excitement.

01

Never fabricate data

Every price, indicator, and COT figure comes from a live or cached tool call in the current run.

02

Risk before reward

Minimum 1.5 R:R to first target. Position size derived from defined risk percentage.

03

Conservative probabilities

Stated probabilities are calibrated and capped — never above 75% for a single idea.

04

Free sources only

Yahoo, Stooq, CFTC public feeds, optional free FRED key. No paid data required to run.
