How it Works

A disciplined pipeline from data to decision.

  1. 1

    Fetch & cache

    OHLCV from Yahoo → Stooq fallback. Macro yields, COT, calendar (best-effort). SQLite cache with freshness rules.

  2. 2

    Compute indicators

    EMAs, ATR, RSI, structure swings, regime proxies — all in pure code. No guessed values.

  3. 3

    Confluence score

    HTF bias, location, momentum, intermarket/macro, events, positioning → 0–100 score and grade.

  4. 4

    Trade construction

    Only if grade and R:R pass. Entry, SL, TP1–3, suggested lots from risk %, invalidation text.

  5. 5

    Report & artifacts

    Markdown report (~1k words), signals.json, optional chart and Pine snippet. Timestamped under out/YYYY-MM-DD_SYMBOL/.

Non-negotiable: Never fabricate data. Risk before reward. No-trade is valid. Probabilities stay conservative.

Educational analysis only. Not financial advice.
