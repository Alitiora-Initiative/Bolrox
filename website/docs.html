Documentation

Install, run, and interpret outputs.

Requirements

Python 3.10 or newer. Internet access for price and positioning feeds.

Install

git clone https://github.com/Jaymn2006/Bolrox.git
cd Bolrox
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

Commands

CommandDescription
python main.py STATUSShow config and readiness
python main.py RUN EURUSDFull pipeline for one symbol
python main.py RUN ALLDefault symbols (XAUUSD, EURUSD, USDJPY)

Output layout

Each run writes under out/YYYY-MM-DD_SYMBOL/:

  • report.md — narrative analysis report
  • signals.json — structured trade ideas, or an empty list

Optional configuration

Create a .env file with a free FRED_API_KEY for additional macro series. Core sources remain free without it. Symbol lists, risk percentage, and grade thresholds live in config.yaml.
