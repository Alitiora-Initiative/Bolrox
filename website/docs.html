Documentation

Quick start and commands.

Install

git clone https://github.com/Jaymn2006/Bolrox.git
cd Bolrox
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

Commands

CommandDescription
python main.py STATUSShow config and readiness
python main.py RUN EURUSDFull pipeline for one symbol
python main.py RUN ALLDefault symbols (XAUUSD, EURUSD, USDJPY)

Output

Each run writes under out/YYYY-MM-DD_SYMBOL/:

  • report.md — analysis report
  • signals.json — structured trade ideas (or empty)

Optional

Create a .env with a free FRED_API_KEY for richer macro data. All core sources remain free without it.
